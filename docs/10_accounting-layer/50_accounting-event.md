# ASM Accounting Event v1.0

## Purpose

This document defines Accounting Events introduced by the Accounting
Layer of ASM.

An Accounting Event represents an event recognized by an accounting
system that produces an Accounting Effect.

The Accounting Event connects economic reality with Accounting State
transitions.

---

## Economic Event and Accounting Event

The Formal Core defines an Event:

$$
e\in\mathcal{E}
$$

The Accounting Layer specializes this concept.

**Symbol:**

$$
e_{acc}
$$

**Formal expression:**

$$
e_{acc}\in\mathcal{E}_{acc}
$$

An Accounting Event is an event recognized as relevant for Accounting
State changes.

---

## Accounting Event Space

**Definition:**

The Accounting Event Space represents all events that may change an
Accounting State.

**Symbol:**

$$
\mathcal{E}_{acc}
$$

The relationship with the Formal Core Event Space is:

$$
\iota_E:
\mathcal{E}_{acc}
\rightarrow
\mathcal{E}
$$

---

## Recognition Function

An economic observation is transformed into an Accounting Event through
recognition.

The recognition function is:

$$
R_{acc}
:
\mathcal{Z}_{acc}
\times
\Theta_{acc}
\times
\mathcal{M}_{acc}
\rightarrow
\mathcal{E}_{acc}
$$

where:

- $\mathcal{Z}_{acc}$ represents accounting evidence.
- $\Theta_{acc}$ represents accounting policies.
- $\mathcal{M}_{acc}$ represents accounting parameters.

---

## Accounting Event Definition

An Accounting Event is defined as:

$$
e_{acc}
=
R_{acc}(z,\theta,m)
$$

where:

$$
z\in\mathcal{Z}_{acc}
$$

$$
\theta\in\Theta_{acc}
$$

$$
m\in\mathcal{M}_{acc}
$$

---

## Accounting Event and Effect

Every Accounting Event generates an Accounting Effect.

The Accounting Effect Function is:

$$
\alpha_{acc}
:
\mathcal{E}_{acc}
\rightarrow
\Delta\mathcal{S}_{acc}
$$

Therefore:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

The relationship is:

$$
e_{acc}
\rightarrow
\alpha_{acc}(e_{acc})
$$

---

## Example: Cash Sale

Consider the economic situation:

"An entity sells goods and receives cash."

The observation is:

$$
z\in\mathcal{Z}_{acc}
$$

Accounting recognition produces:

$$
e_{acc}
=
R_{acc}(z,\theta,m)
$$

The Accounting Effect is:

$$
\alpha_{acc}(e_{acc})
=
(+\Delta Cash,+\Delta Revenue)
$$

The Accounting State transition is:

$$
S_{acc,t+1}
=
\delta_{acc}
(
S_{acc,t},
\alpha_{acc}(e_{acc})
)
$$

---

## Accounting Event Is Not Reality

An Accounting Event is not identical to an economic event.

Formally:

$$
Economic\ Event
\neq
Accounting\ Event
$$

because recognition rules determine whether an event affects Accounting
State.

---

## Accounting Event Is Not Journal Entry

An Accounting Event is also not identical to a Journal Entry.

The relationship is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Journal\ Representation
$$

Therefore:

$$
e_{acc}
\neq
j
$$

A Journal Entry is a representation of the Effect generated by an
Accounting Event.

---

## Consequence

ASM separates:

| Concept | Meaning |
| --- | --- |
| Economic Event | What occurs in economic reality |
| Accounting Evidence | Observable information |
| Accounting Event | Recognized accounting occurrence |
| Accounting Effect | Change in Accounting State |
| Journal Entry | Representation of the Effect |

The complete accounting flow is:

$$
Reality
\rightarrow
Evidence
\rightarrow
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
\rightarrow
Financial\ Representation
$$
