# ASM Accounting Layer Overview v1.1

## Purpose

This document provides an overview of the Accounting Layer of the
Accounting State Model (ASM).

The Accounting Layer specializes the Formal Core for accounting domains.

The Formal Core defines a general mathematical framework for modeling
systems as event-driven state transitions.

The Accounting Layer introduces accounting-specific semantics,
structures, and constraints.

---

## Relationship with Formal Core

The Formal Core defines the general model:

$$
Event
\rightarrow
Effect
\rightarrow
State
$$

The Accounting Layer specializes these concepts:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
$$

The relationship between the two layers is:

$$
Formal\ Core
\rightarrow
Accounting\ Layer
$$

The Formal Core provides the general structure.

The Accounting Layer specializes this structure with accounting semantics
and constraints.

---

## Purpose of Accounting Layer

The Accounting Layer models an economic entity as a system whose state
changes through recognized Accounting Events.

The fundamental flow is:

$$
Economic\ Reality
\rightarrow
Accounting\ Event
\rightarrow
Accounting\ History
\rightarrow
Accounting\ State
\rightarrow
Financial\ Representation
$$

The state transition mechanism is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
$$

---

## Core Concepts

The Accounting Layer introduces the following concepts.

| Concept | Meaning |
| --- | --- |
| Accounting Event | A recognized economic occurrence |
| Accounting Effect | A change generated by an Accounting Event |
| Accounting History | An ordered record of Accounting Events |
| Accounting State | The current accounting condition derived from History |
| Accounting Structure | The dimensions and constraints of Accounting State |
| Double Entry | A representation of Accounting Effects |
| Financial Representation | A purpose-dependent view of Accounting State |

---

## Accounting Flow

The complete accounting model is:

$$
\mathcal{R}_{econ}
\rightarrow
\mathcal{Z}_{acc}
\rightarrow
\mathcal{E}_{acc}
\rightarrow
\mathcal{H}_{acc}
\rightarrow
\mathcal{S}_{acc}
\rightarrow
\mathcal{Y}_Q
$$

where:

- $\mathcal{R}_{econ}$ represents accounting-relevant economic reality.
- $\mathcal{Z}_{acc}$ represents accounting evidence.
- $\mathcal{E}_{acc}$ represents Accounting Event Space.
- $\mathcal{H}_{acc}$ represents Accounting History.
- $\mathcal{S}_{acc}$ represents Accounting State Space.
- $\mathcal{Y}_Q$ represents purpose-dependent representations.

The state transition inside the model is:

$$
e_{acc}
\rightarrow
\alpha_{acc}(e_{acc})
\rightarrow
S_{acc,t+1}
$$

where:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

---

## Accounting Event and Effect

An Accounting Event generates an Accounting Effect.

The relationship is:

$$
e_{acc}
\rightarrow
\alpha_{acc}(e_{acc})
$$

where:

$$
e_{acc}\in\mathcal{E}_{acc}
$$

and:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

The Accounting Effect represents the change caused by the Accounting
Event.

---

## Accounting History

Accounting Events are accumulated as Accounting History.

$$
H_{acc}(t)
\in
(\mathcal{E}_{acc}\times T)^*
$$

Accounting History records what occurred.

The Accounting State is derived from accumulated History:

$$
S_{acc,t}
=
G_{acc}(H_{acc}(t))
$$

Therefore:

$$
Accounting\ State
\neq
Accounting\ History
$$

History preserves events.

State represents the current condition derived from those events.

---

## Accounting State Transition

The central transition of the Accounting Layer is:

$$
S_{acc,t+1}
=
\delta_{acc}
(
S_{acc,t},
\alpha_{acc}(e_{acc})
)
$$

where:

- $S_{acc,t}$ represents the current Accounting State.
- $e_{acc}$ represents an Accounting Event.
- $\alpha_{acc}(e_{acc})$ represents the generated Accounting Effect.
- $\delta_{acc}$ represents the Accounting State Transition Function.

---

## Accounting Structure

The Accounting State is not an arbitrary collection of values.

It is defined by:

1. State dimensions.
2. Constraints between dimensions.
3. Valid transition rules.

The structure of Accounting State is introduced in:

$$
20\text{-}accounting\text{-}structure.md
$$

---

## Double Entry Perspective

Traditional accounting often begins with Journal Entries.

ASM takes a different approach.

The order is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Journal\ Representation
$$

A Journal Entry represents an Accounting Effect.

It is not the source of accounting state transition.

---

## Financial Representation Perspective

Financial representations are generated from Accounting History.

The general representation function is:

$$
F_Q:
\mathcal{H}_{acc}
\rightarrow
\mathcal{Y}_Q
$$

Different purposes may generate different representations from the same
Accounting History.

Therefore:

$$
F_{Q_1}(H_{acc})
\neq
F_{Q_2}(H_{acc})
$$

may hold.

## Summary

The Accounting Layer extends ASM from a general state transition model
into an accounting domain model.

The fundamental structure is:

$$
Economic\ Reality
\rightarrow
Accounting\ Event
\rightarrow
Accounting\ History
\rightarrow
Accounting\ State
\rightarrow
Financial\ Representation
$$

The internal transition mechanism is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
$$

ASM models accounting as:

$$
\boxed{
A\ constrained\ state\ transition\ system\ over\ economic\ events
}
$$
