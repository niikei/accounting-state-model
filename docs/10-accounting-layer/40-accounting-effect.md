# ASM Accounting Effect v1.2

## Purpose

This document defines the concept of Accounting Effect in the Accounting
Layer of the Accounting State Model (ASM).

The purpose is to define how Accounting Events produce changes in
Accounting State.

Accounting Effect represents the state change generated by an Accounting
Event.

---

## Relationship with Formal Core

The Formal Core defines Effect as:

$$
\alpha(e)\in\Delta\mathcal{S}
$$

An Effect represents the change generated by an Event.

The Accounting Layer specializes this concept:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

where:

- $e_{acc}$ represents an Accounting Event.
- $\alpha_{acc}(e_{acc})$ represents an Accounting Effect.

---

## Accounting Event and Effect

An Accounting Event represents:

"What occurred in the accounting model?"

An Accounting Effect represents:

"What changed in Accounting State?"

The relationship is:

$$
e_{acc}
\rightarrow
\alpha_{acc}(e_{acc})
$$

The Event is the causal input.

The Effect is the generated change.

Therefore:

$$
Accounting\ Event
\neq
Accounting\ Effect
$$

---

## Formal Definition

The Accounting Effect Function is:

$$
\alpha_{acc}:
\mathcal{E}_{acc}
\rightarrow
\Delta\mathcal{S}_{acc}
$$

For:

$$
e_{acc}\in\mathcal{E}_{acc}
$$

the generated Effect is:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

An Accounting Effect is not an Accounting State.

It is a change applied to an existing Accounting State.

---

## Effect and State Transition

The Accounting State Transition Function is:

$$
\delta_{acc}:
\mathcal{S}_{acc}
\times
\Delta\mathcal{S}_{acc}
\rightarrow
\mathcal{S}_{acc}
$$

The transition is:

$$
S_{acc,t+1}
=
\delta_{acc}
(
S_{acc,t},
\alpha_{acc}(e_{acc})
)
$$

Therefore:

$$
Effect
\neq
State
$$

and:

$$
Effect
\neq
Transition
$$

Effect describes the change.

Transition describes the operation that applies the change.

---

## Effect as Change Vector

An Accounting Effect may be represented as a change vector:

$$
\alpha_{acc}(e_{acc})
=
(
\Delta A,
\Delta L,
\Delta E
)
$$

where:

- $\Delta A$ represents Asset change.
- $\Delta L$ represents Liability change.
- $\Delta E$ represents Equity change.

Because Accounting State satisfies:

$$
A-L-E=0
$$

a valid Effect must preserve:

$$
\Delta A-\Delta L-\Delta E=0
$$

Therefore:

$$
Valid\ Effect
\rightarrow
Valid\ Accounting\ State
$$

---

## Effect and Flow

An Accounting Effect represents a single instantaneous change.

Therefore:

$$
Effect
\neq
Flow
$$

Flow is obtained by aggregating Effects over a period.

For:

$$
I=[t_0,t_1]
$$

the accumulated Flow is:

$$
Flow(I)
=
\sum_{e\in H_I}
\alpha_{acc}(e)
$$

Therefore:

$$
Flow
=
Aggregation(Effects)
$$

Flow represents accumulated changes.

Effect represents one change.

---

## Effect Projection

A single Accounting Effect may affect multiple accounting dimensions.

The position change is:

$$
\alpha_{acc}(e)
=
(
\Delta A,
\Delta L,
\Delta E
)
$$

The same Effect may be projected into period-based dimensions:

$$
\Delta\Pi
$$

representing Performance Flow contribution.

and:

$$
\Delta\Phi_C
$$

representing Cash Flow contribution.

These are different views of the same underlying Accounting Effect.

---

## Double Entry Relationship

Double Entry represents Accounting Effects.

The causal order is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Journal\ Representation
$$

A Journal Entry describes the Effect.

It does not generate the Effect.

Therefore:

$$
Journal\ Representation
\neq
Accounting\ Effect
$$

---

## Effect Preservation

Valid Accounting Effects preserve Accounting Constraints.

If:

$$
A_t-L_t-E_t=0
$$

and:

$$
\alpha_{acc}(e_{acc})
$$

is valid, then:

$$
(A_t+\Delta A)
-
(L_t+\Delta L)
-
(E_t+\Delta E)
=
0
$$

Therefore:

$$
Valid\ Effect
\rightarrow
Valid\ State
$$

---

## Summary

An Accounting Effect is the mathematical change generated by an
Accounting Event.

The fundamental structure is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
$$

The Accounting Effect is:

- generated by an Accounting Event
- a change vector in Accounting State Space
- applied through State Transition
- distinct from State
- distinct from Flow
- represented by Double Entry

ASM therefore defines:

$$
\boxed{
Effect\ is\ the\ mathematical\ unit\ of\ accounting\ state\ change
}
$$
