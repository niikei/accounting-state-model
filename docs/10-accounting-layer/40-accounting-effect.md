# ASM Accounting Effect v1.1

## Purpose

This document defines the concept of Accounting Effect in the Accounting
Layer of the Accounting State Model (ASM).

The purpose is to define how Accounting Events produce changes in
Accounting State.

Accounting Effect represents the change generated by an Accounting Event.

---

## Relationship with Formal Core

The Formal Core defines Effect as:

$$
\alpha(e)\in\Delta\mathcal{S}
$$

An Effect represents the state change produced by an Event.

The Accounting Layer specializes this concept:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

where:

- $e_{acc}$ represents an Accounting Event.
- $\alpha_{acc}(e_{acc})$ represents an Accounting Effect.

---

## Accounting Event and Effect

An Accounting Event represents:

"What occurred?"

An Accounting Effect represents:

"What changed because of it?"

The relationship is:

$$
e_{acc}
\rightarrow
\alpha_{acc}(e_{acc})
$$

The Event is the causal input.

The Effect is the resulting state change.

Therefore:

$$
Accounting\ Event
\neq
Accounting\ Effect
$$

---

## Formal Definition

The Accounting Effect Function is:

$$
\alpha_{acc}:
\mathcal{E}_{acc}
\rightarrow
\Delta\mathcal{S}_{acc}
$$

For an Accounting Event:

$$
e_{acc}\in\mathcal{E}_{acc}
$$

the generated Effect is:

$$
\alpha_{acc}(e_{acc})
\in
\Delta\mathcal{S}_{acc}
$$

An Accounting Effect describes the change applied to an Accounting
State.

---

## Effect and State Transition

An Accounting Effect does not directly represent a State.

It represents a change applied to a State.

The State Transition Function is:

$$
\delta_{acc}:
\mathcal{S}_{acc}
\times
\Delta\mathcal{S}_{acc}
\rightarrow
\mathcal{S}_{acc}
$$

The transition is:

$$
S_{acc,t+1}
=
\delta_{acc}
(
S_{acc,t},
\alpha_{acc}(e_{acc})
)
$$

Therefore:

$$
Effect
\neq
State
$$

and:

$$
Effect
\neq
Transition
$$

---

## Effect as Change Vector

An Accounting Effect may be represented as a change vector.

For example:

$$
\Delta S_{acc}
=
(\Delta A,\Delta L,\Delta E)
$$

where:

- $\Delta A$ represents change in Assets.
- $\Delta L$ represents change in Liabilities.
- $\Delta E$ represents change in Equity.

The Accounting Constraint requires:

$$
\Delta A-\Delta L-\Delta E=0
$$

Therefore, valid Effects preserve accounting structure.

---

## Effect and Flow

An Accounting Effect represents a single state change.

It is not a Flow.

Formally:

$$
Effect
\neq
Flow
$$

A Flow is obtained by aggregating Effects over a period.

For:

$$
I=[t_0,t_1]
$$

the accumulated Flow is:

$$
Flow(I)
=
\sum_{e\in H_I}
\alpha(e)
$$

Therefore:

$$
Flow
=
Aggregation(Effects)
$$

Flow is a derived representation of accumulated Effects.

---

## Effect Projection

An Accounting Effect may affect different accounting dimensions.

For example:

$$
\alpha_{acc}(e)
=
(
\Delta A,
\Delta L,
\Delta E
)
$$

The same Effect may also generate:

$$
\Delta\Pi
$$

as Performance Flow contribution.

and:

$$
\Delta\Phi_C
$$

as Cash Flow contribution.

These are projections of the same underlying change.

---

## Double Entry Relationship

Traditional accounting represents Effects through Journal Entries.

ASM places Journal Representation after Effect generation.

The order is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Journal\ Representation
$$

A Journal Entry describes the Effect.

It does not create the Effect.

---

## Effect Preservation

Valid Accounting Effects preserve Accounting Constraints.

If:

$$
C(S_t)=0
$$

and:

$$
Valid(e_{acc})
$$

then:

$$
C(
\delta_{acc}
(
S_t,
\alpha_{acc}(e_{acc})
)
)
=
0
$$

Therefore:

Valid Effects maintain valid Accounting States.

## Summary

An Accounting Effect is the state change generated by an Accounting Event.

The fundamental structure is:

$$
Accounting\ Event
\rightarrow
Accounting\ Effect
\rightarrow
Accounting\ State
$$

The Accounting Effect is:

- generated by an Accounting Event
- applied through a State Transition
- distinct from State
- distinct from Flow
- represented by Double Entry

ASM therefore defines:

$$
\boxed{
Effect\ is\ the\ mathematical\ unit\ of\ accounting\ state\ change
}
$$
